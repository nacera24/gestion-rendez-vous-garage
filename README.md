Application Web de gestion de rendez-vous automobiles — React, Redux Toolkit, API REST, Django REST Framework et MySQL
Développement d’une application full-stack intégrant une API REST sécurisée par JWT, la gestion CRUD des clients, véhicules, rendez-vous et factures, ainsi que la documentation Swagger et les tests avec Postman.

Technologies à indiquer :

React, JavaScript, Redux Toolkit, Axios, Python, Django REST Framework, MySQL, JWT,  API REST, Swagger, Postman et Bootstrap.
